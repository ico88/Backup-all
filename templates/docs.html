  • Aggiungi prima l'host XCP-ng dalla tab dedicata
Per ripristinare un XVA: xe vm-import filename=backup.xva sull'host XCP-ng.

Impostazioni

Vai su Impostazioni → sezione SMTP. Inserisci host, porta, utente e password del tuo server mail, poi usa il pulsante Test SMTP per verificare che arrivi.

Hai un problema?
Il test verifica solo SSH/porta aperta. Il backup può fallire per: permessi insufficienti sulla cartella destinazione sul NAS, mysqldump/pg_dump non installato sulla sorgente, disco pieno, timeout su file grandi. Soluzione: vai su Storico, apri il job fallito e leggi i log — il messaggio di errore esatto è lì.
Vai su Job di Backup → trova il job → clicca il pulsante ▶ Esegui ora. Parte immediatamente in background. Segui l'avanzamento nello Storico.
Il ripristino è manuale. I file sono nel percorso base della destinazione, in sottocartelle [nome-server]/[data]/.
Linux: copia con rsync o SCP.
Windows: usa wbadmin start recovery o la GUI "Backup di Windows Server".
VMware OVF: importa il file dal pannello ESXi (Actions → Deploy OVF Template).
XCP-ng XVA: xe vm-import filename=backup.xva sull'host XCP-ng.
Dipende dal tipo di backup:
  • Linux / Windows (rsync): rsync è incrementale — al secondo tentativo trasferisce solo i file mancanti o modificati. Di fatto riprende da dove si era fermato.
  • VMware ESXi / XCP-ng (streaming): il backup ricomincia da capo. Lo streaming diretto non prevede resume parziale — ma le VM di solito si completano in un'unica sessione.
  • Windows bare-metal (wbadmin): wbadmin gestisce internamente l'incrementale se la destinazione esiste già.
Per riprovare manualmente un backup fallito vai su Storico e clicca il pulsante Riprova accanto al run fallito.
sudo bash /opt/backup-all/update.sh
Aggiorna codice, dipendenze Python e riavvia il servizio. Database e configurazione vengono preservati.
Verifica che ovftool non sia ancora attivo:
ps aux | grep ovftool
Se il processo non esiste, riavvia il servizio — i job bloccati vengono chiusi automaticamente:
sudo systemctl restart backup-all
